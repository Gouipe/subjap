# Rang de fréquence attendu des mots d'un sous-titre (public/frequency/README.md).
#
# Une ligne : sous-titre → unités séparées par « | ». « unité=rang » vérifie le
# rang JPDB affiché pour ce mot, « unité=- » qu'il n'en a aucun (mot rare ou
# mot grammatical) ; sans « = », seule la surface est vérifiée. Tout correctif
# de fréquence ajoute ici le mot qui l'a révélé, et les mots proches qui ne
# doivent pas bouger.
# Lancer : npm.cmd test -- frequency-corpus

# ── Mots grammaticaux : pas de rang, même en tête de liste ──────────────────
猫がいる → 猫=1509|が=-|いる=18
後で → 後=186|で=-
