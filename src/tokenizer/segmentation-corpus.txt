# Découpage attendu des sous-titres en unités cliquables (docs/tokenization.md).
#
# Une ligne : sous-titre → unités séparées par « | ». « unité=identité » vérifie
# aussi le mot de base (tête JMdict ou lexème UniDic) ; sans « = », seule la
# surface est vérifiée. Tout correctif de découpage ajoute ici la phrase qui
# l'a révélé, et ce qui doit rester séparé autant que ce qui doit fusionner.
# Lancer : npm.cmd test -- segmentation

# ── Verbes et adjectifs conjugués ───────────────────────────────────────────
話せば分かる → 話せば=話す|分かる
高ければ買わない → 高ければ=高い|買わない=買う
高くない → 高くない=高い
静かだった → 静かだった=静か
食べてしまった → 食べてしまった=食べる
見ている → 見ている=見る
行っちゃう → 行っちゃう=行く
書いとく → 書いとく=書く
書きながら → 書き=書く|ながら

# ── Obligation, interdiction, permission ────────────────────────────────────
話さなければいけない → 話さなければいけない=話す
行かないといけない → 行かないといけない=行く
勉強しなきゃ → 勉強|しなきゃ
食べてはいけない → 食べてはいけない=食べる
食べちゃだめ → 食べちゃだめ=食べる
食べなくてもいい → 食べなくてもいい=食べる

# ── Ordres (なさい, な) et défense ──────────────────────────────────────────
従いなさい → 従いなさい=従う
休みなさいませ → 休みなさいませ=休む
見なさい → 見なさい=見る
食べなよ → 食べな=食べる|よ
食べるな → 食べる|な

# ── Noms, suffixes, exclamations ────────────────────────────────────────────
勉強する → 勉強|する
こいつら → こいつら=此奴
田中さん → 田中|さん
フンッ → フンッ

# ── Mots qu'UniDic coupe en deux (split-words.ts) ───────────────────────────
実はね → 実は=実は|ね
要は簡単だ → 要は=要は|簡単だ
まずは自己紹介 → まずは=先ずは|自己|紹介
時にはいい → 時には=時には|いい
今では普通だ → 今では=今では|普通|だ
いつかは分かる → いつかは=何時かは|分かる
ちなみに → ちなみに=因みに
とっくに終わった → とっくに=疾っくに|終わった
一気に飲んだ → 一気に=一気に|飲んだ
申し訳ない → 申し訳ない=申し訳ない
申し訳なかった → 申し訳なかった=申し訳ない
申し訳ありませんでした → 申し訳ありませんでした=申し訳ない
とんでもございません → とんでもございません=とんでも無い
もったいない → もったいない=勿体ない
# … mais pas quand le sens est autre.
木の実は甘い → 木の実|は|甘い
机の上は → 机|の|上|は
子供の時には → 子供|の|時|に|は
今ではなく明日だ → 今|で|は|なく|明日|だ
今ではありません → 今|で|は|ありません

# ── Expressions nom + particule + verbe (liste embarquée) ──────────────────
空気を読む → 空気を読む=空気を読む
空気を読めない → 空気を読めない=空気を読む
空気読めない → 空気読めない=空気を読む
気にしないで → 気にしないで=気にする
手を出すな → 手を出す=手を出す|な
腹が立つ → 腹が立つ=腹が立つ
腹がたつ → 腹がたつ=腹が立つ
はらがたつ → はらがたつ=腹が立つ
ムキになる → ムキになる=向きになる
席に着け → 席に着け=席に着く
一緒にしよう → 一緒にしよう=一緒にする
気がする → 気がする=気がする
役に立つ → 役に立つ=役に立つ
# … mais pas les tournures de grammaire, les homophones ni le sens littéral.
そこをつく → そこ|を|つく
ことができる → こと|が|できる
食べることにする → 食べる|こと|に|する
君のためにする → 君|の|ため|に|する
目を見て話して → 目|を|見て|話して
後になって分かった → 後|に|なって|分かった
空気を全然読めない → 空気|を|全然|読めない
空気も読めない → 空気|も|読めない
