# Découpage attendu des sous-titres en unités cliquables (docs/tokenization.md).
#
# Une ligne : sous-titre → unités séparées par « | ». « unité=identité » vérifie
# aussi le mot de base (tête JMdict ou lexème UniDic) ; sans « = », seule la
# surface est vérifiée. Tout correctif de découpage ajoute ici la phrase qui
# l'a révélé, et ce qui doit rester séparé autant que ce qui doit fusionner.
# Lancer : npm.cmd test -- segmentation

# ── Verbes et adjectifs conjugués ───────────────────────────────────────────
話せば分かる → 話せば=話す|分かる
高ければ買わない → 高ければ=高い|買わない=買う
高くない → 高くない=高い
静かだった → 静かだった=静か
食べてしまった → 食べてしまった=食べる
見ている → 見ている=見る
行っちゃう → 行っちゃう=行く
書いとく → 書いとく=書く
書きながら → 書き=書く|ながら

# ── Obligation, interdiction, permission ────────────────────────────────────
話さなければいけない → 話さなければいけない=話す
行かないといけない → 行かないといけない=行く
勉強しなきゃ → 勉強|しなきゃ
食べてはいけない → 食べてはいけない=食べる
食べちゃだめ → 食べちゃだめ=食べる
食べなくてもいい → 食べなくてもいい=食べる

# ── Ordres (なさい, な) et défense ──────────────────────────────────────────
従いなさい → 従いなさい=従う
休みなさいませ → 休みなさいませ=休む
見なさい → 見なさい=見る
食べなよ → 食べな=食べる|よ
食べるな → 食べる|な
行くなよ → 行く|な|よ
早く寝な → 早く|寝な=寝る
寝なさいよ → 寝なさい=寝る|よ
勉強しなさい → 勉強|しなさい=為る

# ── Noms, suffixes, exclamations ────────────────────────────────────────────
勉強する → 勉強|する
こいつら → こいつら=此奴
田中さん → 田中|さん
フンッ → フンッ
# Identité sans la glose d'UniDic (テレビ-television, 君-代名詞).
テレビを見る → テレビ=テレビ|を|見る
コーヒーを飲む → コーヒー=コーヒー|を|飲む
バイトに行く → バイト=バイト|に|行く
君が好きだ → 君=君|が|好きだ

# ── Mots qu'UniDic coupe en deux (split-words.ts) ───────────────────────────
実はね → 実は=実は|ね
じつは → じつは=実は
実際は違う → 実際は=実際は|違う
恐らくは無理だ → 恐らくは=恐らくは|無理|だ

ときには泣く → ときには=時には|泣く
今では普通だ → 今では=今では|普通|だ
今では誰も → 今では=今では|誰|も
いつかは分かる → いつかは=何時かは|分かる
ちなみに → ちなみに=因みに
とっくに終わった → とっくに=疾っくに|終わった
一気に飲んだ → 一気に=一気に|飲んだ
さっさと行け → さっさと=さっさと|行け=行く
申し訳ない → 申し訳ない=申し訳ない
申し訳なかった → 申し訳なかった=申し訳ない
申し訳ありませんでした → 申し訳ありませんでした=申し訳ない

とんでもございません → とんでもございません=とんでも無い
とんでもない → とんでもない=とんでも無い
もったいない → もったいない=勿体ない

# … mais pas quand le sens est autre.
木の実は甘い → 木の実|は|甘い
机の上は → 机|の|上|は
子供の時には → 子供|の|時|に|は
疲れた時には寝る → 疲れた|時|に|は|寝る
暑い時には → 暑い|時|に|は
その時には遅い → その|時|に|は|遅い
今ではなく明日だ → 今|で|は|なく|明日|だ
今ではありません → 今|で|は|ありません
今でもいい → 今|で|も|いい

空気を読む → 空気を読む=空気を読む

# を/が omis, aussi après un nom en kana ou katakana écrit tel que l'entrée.
嘘つく → 嘘つく=嘘をつく
バカ言ってんじゃない → バカ言って=馬鹿を言う|んじゃない
ぜいたく言わない → ぜいたく言わない=贅沢を言う
バランス取る → バランス取る=バランスを取る
# … mais pas les tournures de grammaire, les homophones ni le sens littéral.
そこをつく → そこ|を|つく
ことができる → こと|が|できる
# Particule omise : pas devant する, ni après un nom kana trouvé par sa seule lecture.
無理する → 無理|する
ムキなる → ムキ|なる
ことあるごとに怒る → こと|ある|ごと|に|怒る
食べることにする → 食べる|こと|に|する

目を見て話して → 目|を|見て|話して
後になって分かった → 後|に|なって|分かった
空気を全然読めない → 空気|を|全然|読めない
空気も読めない → 空気|も|読めない
信じろ → 信じろ=信ずる    # affiché 信じる, lexème partagé avec 信ずる
信ぜよ → 信ぜよ=信ずる
いけない！ → いけない=行けない|！    # mot à part (mal, il ne faut pas), pas 行く
いけません → いけません=行けない

学校に行けない → 学校|に|行けない=行く
